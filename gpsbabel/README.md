# gpsbabel tools

## gpxtrack2gps

Install:

```sh
cp gpxtrack2gps.desktop ~/.local/share/application
```

Use:

- navigate with file manager to gpx file
- right click open with...
- select GpxTrack2Gps
- gpx is copied to Garmin Gps

## How to copy a new map

- connect GPS with USB
- switch on the GPS
- in the GPS menu swich on USB mass storage
- download a map from for example https://www.openfietsmap.nl/
- copy gmapsupp.img to the GPS in the Garmin folder
